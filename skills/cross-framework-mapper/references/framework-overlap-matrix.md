# Cross-Framework Data Point Overlap Matrix

This reference maps ~80 key sustainability data points across six major frameworks: ESRS, GRI, ISSB/SASB, EU Taxonomy, CBAM, and SFDR. Use this to identify reporting efficiencies and reduce duplication.

> **Version caveat (July 2026)**: the ESRS column references the original 2023 datapoint IDs, valid for reporting through FY2026. The revised ESRS (2026), adopted 3 July 2026 and applicable from FY2027, cut mandatory datapoints by 61% — verify each ESRS reference against the revised set when planning FY2027+ collection. The SFDR column reflects the current Art. 6/8/9 + PAI regime; SFDR 2.0 (in trilogue) would replace it with Sustainable/Transition/ESG Basics categories.

**Legend**:
- Cell contains the specific disclosure reference within each framework
- `—` means not required by that framework
- `Yes` means required but without a specific numbered disclosure
- `DNSH` = Do No Significant Harm criteria
- `TSC` = Technical Screening Criteria
- `PAI` = Principal Adverse Impact indicator
- `Min safeguards` = Minimum Safeguards requirement

### Key methodology differences to watch
| Data Point | Framework | Key Difference |
|-----------|-----------|---------------|
| GHG Scope 2 | ESRS vs GRI | ESRS requires both location-based and market-based; GRI allows choice |
| GHG Scope 3 | ESRS vs ISSB | ESRS requires all material categories; ISSB allows phased approach |
| Energy | ESRS vs EU Taxonomy | ESRS uses total consumption; Taxonomy requires activity-level allocation |
| Water stress | ESRS vs SFDR | ESRS uses WRI Aqueduct baseline; SFDR references areas with high water stress |
| Waste | ESRS vs EU Taxonomy | ESRS entity-level; Taxonomy requires activity-level for DNSH |
| Carbon intensity | CBAM vs ESRS | CBAM requires product-specific; ESRS allows entity-level |
| Gender pay gap | ESRS vs SFDR | ESRS requires adjusted/unadjusted; SFDR references unadjusted mean |
| Human rights DD | ESRS vs CSDDD | ESRS is disclosure; CSDDD is a legal obligation with enforcement |
| Hazardous waste | ESRS vs EU Taxonomy | ESRS total entity; Taxonomy per-activity for DNSH assessment |
| Biodiversity | ESRS vs EU Taxonomy | ESRS qualitative + quantitative; Taxonomy DNSH requires EIA evidence |
| Training hours | ESRS vs GRI | ESRS S1-13 requires by gender/category; GRI 404-1 allows aggregate |
| Board oversight | ESRS vs ISSB | ESRS GOV-1 broader (all sustainability); ISSB S2 climate-specific governance |
| Collective bargaining | ESRS vs GRI | Both require %, ESRS adds geographic breakdown |
| Anti-corruption | ESRS vs GRI | GRI 205 more detailed on risk assessment; ESRS G1 broader governance scope |
| Water discharge | ESRS vs GRI | Both require quality data; ESRS E3-4 adds receiving water body sensitivity |
| Deforestation | ESRS vs SFDR | ESRS E4 qualitative + policy; SFDR PAI #15 binary exposure metric |

## Efficiency Analysis by Company Type

### Large EU Listed Company (ESRS mandatory + EU Taxonomy + SFDR exposure)
- **Total unique data points needed**: ~82
- **Data points shared across 2+ frameworks**: ~55 (67%)
- **Potential collection effort savings**: up to 40% by collecting once, reporting multiple

### Italian SME Entering CSRD (first-time reporter)
- **Recommended starting set**: Priority 1 + Priority 2 data points (~27 data points)
- **Coverage achieved**: ESRS core + EU Taxonomy DNSH + basic SFDR PAI
- **Estimated FTE effort**: 0.5-1.0 FTE for first year, 0.3 FTE ongoing

### Importer of CBAM Goods (e.g., steel, cement, aluminium)
- **Critical overlap**: CBAM D1-D8 + ESRS E1-6 + EU Taxonomy TSC
- **Unique CBAM data**: installation-level emissions, precursor data, carbon price paid
- **Recommended approach**: collect CBAM-specific first (regulatory deadline), then extend to ESRS

### Financial Institution (bank, asset manager, insurer)
- **Critical overlap**: SFDR PAI (mandatory) + ESRS (own operations) + EU Taxonomy (GAR/BTAR)
- **Unique challenge**: need data from investee companies (financed emissions)
- **Recommended approach**: leverage ESRS disclosures from investees to populate SFDR PAI

## Phased Implementation Roadmap

### Year 1: Foundation (Priority 1 data points)
- Collect all 14 Priority 1 data points (serving 4+ frameworks)
- Establish data ownership and collection processes
- Coverage: ~50% of ESRS quantitative requirements, ~70% of SFDR PAI, ~60% of EU Taxonomy DNSH

### Year 2: Expansion (Priority 2 data points)
- Add 13 Priority 2 data points (serving 3 frameworks)
- Improve data quality (move from estimates to measurements)
- Coverage: ~75% of ESRS, ~90% of SFDR PAI, ~80% of EU Taxonomy

### Year 3: Completion (Priority 3-4 data points)
- Add remaining framework-specific data points
- Implement automated data collection where possible
- Achieve full compliance across all applicable frameworks
- Begin benchmarking and target-setting based on historical data
