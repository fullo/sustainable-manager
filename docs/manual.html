User Manual

A practical guide for first-time users. You don't need to master Claude Code — you only need to know what to ask and which skill answers.

Getting started

Skills activate in two ways:

  1. Automatically — write your question in plain language (English or Italian) and Claude activates the right skill from context. Example: "we import steel from Turkey, what do we need to do about CBAM?" activates cbam-compliance.
  2. Explicitly — invoke the skill with its slash command, e.g. /sustainable-manager:eu-regulation-matrix.

Every skill:

  • answers in your language — write in Italian and you get the Italian regulatory layer (Consob, ADM, MASE, CONAI, CAM, RAEE);
  • asks one question at a time — no need to prepare all your data upfront, the skill guides you. "I don't know" is a valid answer;
  • produces outputs that are drafts to review, not certifications: the final judgment belongs to you, your legal counsel, and your auditor.

Realistic starting scenarios

"We're an SME and our bank asked for ESG data"

You're not in CSRD scope (post-Omnibus it takes 1,000+ employees AND €450M turnover), but bank and customer requests are real. Start with eu-regulation-matrix to confirm what does NOT apply to you, then use the core skill citing the VSME standard: data requests from CSRD-scope customers cannot exceed that perimeter.

"Our German customer sent an 80-question questionnaire"

supplier-engagement can read and prioritize questionnaires (and tells you what you can legitimately decline if you have fewer than 1,000 employees). If it touches emissions, scope3-mapper produces first numbers with the spend-based method.

"We import 120 tonnes of steel profiles per year from Turkey"

cbam-compliance: you're above the de minimis threshold (50t cumulative), so you need authorized declarant status; the skill calculates embedded emissions and estimates certificates (purchases open February 2027, declaration due 30 September).

"The CFO wants to know what net-zero costs"

transition-plan-builder, six phases from baseline to CapEx plan. Mind the SBTi version: validations from 1 February 2028 must use the Corporate Net-Zero Standard v2.0.

"We have a data centre and 1,500 laptops; IT asks what to do"

sustainable-it-compliance — see the full case study.

"Marketing wants to put 'carbon neutral platform' on the website"

Stop them, then use sustainable-it-compliance (IT claims) or the core skill (greenwashing detection): from 27 September 2026 the Empowering Consumers Directive bans offset-based neutrality claims.

Analyzing a sustainability report

The core sustainable-manager skill reads an existing report (PDF, Excel, CSV, DOCX) and turns it into a structured, source-anchored assessment. This is the single most common first task — a bank, a customer, or your own board hands you a PDF and asks "is this any good?". How to start — attach the file and write:

Analyze this sustainability report: extract the KPIs, check completeness against the framework, and flag any greenwashing.

The skill works through six steps. You can ask for all of them or stop at any one.

StepWhat the skill doesWhat to watch
1. Identify the frameworkDetermines whether the report is in accordance with a standard, with reference to it, merely inspired by it, or declares nothing. GRI, ESRS, VSME, TNFD, SASB."Inspired by ESRS" is not ESRS compliance — the skill says so explicitly.
2. Extract KPIsPulls quantitative metrics — Scope 1/2/3, energy, water, waste, workforce — each with page number and a verbatim quote.Anti-fabrication rule: if a number isn't in the document, the skill lists it as missing, it never estimates it into the table.
3. Check completenessPresent vs missing disclosures against the applicable framework.What's absent is often more telling than what's shown: Scope 3, baseline year, assurance, double materiality.
4. Detect greenwashingSeparates claims from data and rates each claim on a four-level scale.The reduce-before-offset hierarchy: absolute cuts first, compensation only for the residual.
5. Verify (adversarial)Optionally re-reads the PDF as ground truth to confirm every figure and page. Run /adversarial-verify (a separate skill with its own site) or ask "verify your own analysis against the source".Catches page drift and transcription slips — the cheapest quality gate before a number leaves the building.
6. Summarize & visualizeExecutive summary, strengths/weaknesses, and charts (materiality matrix, emissions breakdown, completeness meter).Outputs are working drafts, not certifications.
The two gotchas that catch everyone: (1) Scope 2 market-based vs location-based — if the report shows a single Scope 2 figure, the skill asks which method, because the gap can exceed 50% for a company buying green energy. (2) Relative vs absolute — a headline "−37% emissions" is almost always an intensity or market-based figure while absolute location-based emissions grow; the skill checks both.

The four greenwashing ratings the skill assigns:

RatingMeaning
SubstantiatedBacked by a specific metric, stated methodology, ideally third-party assurance.
Partially substantiatedData exists but is incomplete, unverified, or lacks context.
UnsubstantiatedA qualitative claim with no supporting data.
MisleadingData exists but is presented so as to create a false impression.

The three most common beginner mistakes

  1. Asking for "everything at once" — skills work in steps. Answer one question at a time; you can always say "I don't know" and the skill will tell you how to estimate or where to find the data.
  2. Treating outputs as final — tables, matrices, and estimates are working drafts with explicit sources and assumptions. Verify them before they go into an official document.
  3. Using the wrong level of skill — this plugin works at the management/compliance level. For technical code audits (green coding patterns, runtime measurements, mobile) use the companion sustainable-code plugin (the gc-* skills): this plugin stops where the IDE begins.
